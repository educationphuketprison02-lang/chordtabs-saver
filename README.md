# Chordtabs Saver

ใส่ชื่อเพลง แล้วโปรแกรมจะค้นหาใน chordtabs.in.th และเซฟรูปเนื้อเพลง+คอร์ดกีต้าร์ให้อัตโนมัติ
โดยตั้งชื่อไฟล์เป็นชื่อเพลง ใส่กี่เพลงก็ได้

## ใช้งานแบบไฟล์เดียว (.exe) — ไม่ต้องติดตั้งอะไร

ดาวน์โหลด `ChordtabsSaver.exe` จากหน้า [Releases](../../releases) (หรือสร้างเองด้วย `build_exe.bat` ดูด้านล่าง)
แล้วก๊อปไปไว้ที่ไหนก็ได้ ในเครื่อง Windows เครื่องไหนก็ได้ แล้วดับเบิลคลิก
(ไฟล์ exe ไม่ได้อยู่ในซอร์สโค้ดเพราะมีขนาดใหญ่ ~74 MB)

- ไม่ต้องลง Python (ในไฟล์ exe มีทุกอย่างอยู่แล้ว)
- โปรแกรมใช้ Microsoft Edge หรือ Chrome ที่มีในเครื่อง (Windows 10/11 มี Edge มาให้อยู่แล้ว)
- ต้องต่ออินเทอร์เน็ต
- รูปจะเซฟไว้ในโฟลเดอร์ `chords` ข้างไฟล์ exe (เปลี่ยนที่เซฟได้ในโปรแกรม)
- ครั้งแรกที่เปิด Windows อาจขึ้นเตือน "Windows protected your PC" ให้กด More info → Run anyway
  (เพราะ exe ไม่ได้ลงลายเซ็นดิจิทัล)

## ใช้งานแบบ Python

```powershell
pip install playwright customtkinter
```

```powershell
python chord_saver.py
```

หรือแบบรายชื่อในไฟล์ (บรรทัดละเพลง ใส่ `--label` ถ้าอยากพิมพ์ชื่อลงบนรูป):

```powershell
python chord_saver.py --label songs.txt
```

## สร้างไฟล์ exe ใหม่ (หลังแก้โค้ด)

ดับเบิลคลิก `build_exe.bat` แล้วจะได้ไฟล์ใหม่ที่ `dist/ChordtabsSaver.exe`

## เคล็ดลับ

- ใส่ชื่อศิลปินต่อท้ายชื่อเพลงเพื่อให้ได้เวอร์ชันที่ถูกต้อง เช่น `ฝนตกไหม Three Man Down`
- วางลิงก์เพลงตรงๆ ได้ เช่น `https://chordtabs.in.th/37709/`
- "ใส่ชื่อไฟล์ไว้ที่มุมขวาล่างของรูป" = พิมพ์ชื่อเพลงลงบนรูป
- "ตั้งชื่อไฟล์ตามชื่อเพลง + ศิลปินจากเว็บ" = ใช้ชื่อเต็มจากเว็บเป็นชื่อไฟล์
- ถ้ามีไฟล์ชื่อซ้ำ จะเติม (2), (3) ให้ ไม่เขียนทับไฟล์เดิม
